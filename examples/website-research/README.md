# Website pages → source packets for AI research

Turn a short list of public website pages into Markdown and source-linked chunks you can inspect before adding them to an AI research or retrieval workflow. This starter uses [Mako Web Content Crawler on Apify](https://apify.com/agency-shift/web-content-crawler) and built-in n8n nodes.

**See the result before creating an account:** [page output](examples/sample-pages.json), [readable homepage Markdown](examples/sample-home.md), and [33 source packets with a coverage report](examples/sample-source-packets.json).

The sample is a real extraction of two Mako-owned pages on **2 October 2026** using Actor build `0.2.2`: two successful pages, 33 chunks, no failed requests and no truncated Markdown. It is a dated example, not a promise that a different website will work. [Input](examples/input.json) · [Run report](examples/sample-run-summary.json) · [Evidence metadata](examples/proof-metadata.json).

## Run the n8n starter

1. Download [website-to-source-packets.json](n8n/website-to-source-packets.json).
2. In n8n, create a workflow and choose **Import from File** from its menu, or choose **Import from URL** and paste the [raw workflow URL](https://raw.githubusercontent.com/valdeircs/scraper-fleet/main/examples/website-research/n8n/website-to-source-packets.json).
3. Create a **Header Auth** credential: header name `Authorization`, value `Bearer YOUR_APIFY_TOKEN`. Select that credential in all five HTTP Request nodes. An Apify account with available credit is required for live runs; keep the token out of the workflow JSON.
4. Review **Configure crawl**. It starts with the same two public Mako URLs used for the sample. To use your own pages, replace `startUrls` with 1–10 explicit URLs; the page budget follows that count.
5. Execute manually. Inspect **Validate pages and build packets** for the coverage report, then **Source packets** for one item per chunk.

[Detailed setup and troubleshooting](docs/n8n-setup.md). The export is inactive and has no schedule, LLM call, embedding service, or CRM write. You decide where the final items go.

```text
Manual start → bounded Apify run → wait for completion
            → check RUN_SUMMARY → check page output → source packets
```

Each packet keeps `content`, `sourceUrl`, `sectionUrl`, `title`, `headingPath`, `crawledAt`, a stable `id`, `contentHash`, `characterCount`, and an `oversized` flag. A retrieval system can store `content` as the passage, preserve the other fields as citation metadata, and use the ID and hash to manage updates. No embedding or factual answer is generated by this starter.

## Cost and scope

The workflow sets an **Actor maximum charge of $0.10 per run**, a **180-second Actor timeout**, 512 MB memory, and build `0.2.2`. It does not retry the run-creation request. Repeated manual executions create separate runs and separate charges.

On 2 October 2026, the Actor's Free-tier startup event was **$0.05**, charged once at this memory setting, with normal run platform usage included; paid-plan discounts may differ. It is a startup charge, not a per-page price. Check the [current Actor pricing](https://apify.com/agency-shift/web-content-crawler) before running. The Actor limit does not include your n8n plan, any downstream tools you add, or separate post-run storage/API costs. Owner test resource usage is not a customer price quote. See [Apify pricing behavior](https://docs.apify.com/actors/running/actors-in-store).

This crawler reads server-rendered HTML. It does not render JavaScript, sign in, solve CAPTCHAs, infer facts, or verify that content is correct. This workflow follows no links and only assesses the supplied URLs. A successful run does not establish whole-site completeness.

The workflow stops if the crawl fails, any supplied page is missing, the report indicates failed or unprocessed requests, or output is empty or truncated. Code blocks or tables can exceed the requested chunk size; those chunks remain intact and carry `oversized: true`. Review that flag before sending content to a system with strict token limits. Chunk sizes are character-based, not token-based.

Treat downloaded text as untrusted source material. If you add an AI step, pass it as reference content and keep any instructions found inside it separate from your system instructions and tool permissions. The starter does not execute source text.
